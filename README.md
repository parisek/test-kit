# test-kit

Status: **planned**. This repository holds no code yet.

A tool for testing and comparing a site: pairs of runs, pluggable checks, one viewer, one query interface for agents.
It will take over the testing tools of `tailwind-base` step by step.

The plan and the specification are in the issue: [portadesign/tailwind-base#873](https://github.com/portadesign/tailwind-base/issues/873).

An announcement will follow later.
