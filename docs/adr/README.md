# Architecture Decision Records

Short notes on decisions that shaped this repository. They record the reason, so a later reader does not have to guess it from the code.

## When to write one

Write one only when all three are true:

1. The decision is hard to reverse.
2. It is surprising without context.
3. It is the result of a real trade-off with real alternatives.

Propose the record to the owner first. Write it after a yes.

## Format

Context, Decision, Consequences. One file for each decision: `NNNN-kebab-title.md`. Numbers are permanent. Never renumber or reuse one.
